Flujo Git ↔ API

Descarga un único archivo desde el servidor (mismo contenido que GET /api/export) o sincroniza desde la raíz del repo con variables TRACKER_API_BASE y TRACKER_API_TOKEN. 

npm run pull-api
npm run push-api
npm run import-export -- descargas/tracker-export.json

Con la API en config.js, los cambios van al servidor (PUT /api/sync). Sin API, vincula los JSON y usa scripts/sync-tracker-data.ps1 para regenerar .data.js. Para alinear Git con Railway: npm run pull-api o descarga tracker-export.json y npm run import-export.
